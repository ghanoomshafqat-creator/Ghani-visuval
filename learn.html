Let's Create

05 / LEARN DESIGN

Start learning.
Start creating.

A simple roadmap for anyone who wants to begin their graphic design journey from the basics.

START HERE

You don't need
to know everything.

Start with the basics, practice regularly and build your skills one project at a time.

WHAT YOU NEED
  • A laptop or computer
  • Basic computer knowledge
  • Creativity and curiosity
  • Time for regular practice
  • A design software to practice with
  • Patience to keep learning

YOUR ROADMAP

Learn it
step by step.

01
FOUNDATION

Understand Design Basics

Learn colours, typography, spacing, alignment, composition and visual hierarchy.

02
TOOLS

Learn Your Design Software

Start learning the tools and features you need to create and edit professional designs.

03
PRACTICE

Recreate & Experiment

Practice by recreating simple designs and then experiment with your own ideas and layouts.

04
PROJECTS

Build Real Projects

Create posters, cards, social media posts, banners, stationery and other useful designs.

05
PORTFOLIO

Build Your Portfolio

Select your strongest work and present it in a clean, professional portfolio.

06
GROW

Start Working With Clients

Learn how to understand requirements, communicate clearly, manage revisions and deliver final files.

BASIC SKILLS

What should you
learn first?

01

Colour

Understand colour combinations and visual balance.

02

Typography

Learn how to choose and combine fonts effectively.

03

Layout

Create clean designs with proper spacing and alignment.

04

Composition

Learn how to arrange elements so the design feels balanced.

05

Branding

Understand how colours, fonts and visuals create identity.

06

Presentation

Learn how to present your designs professionally.

KEEP GOING

Your first design
doesn't have to be perfect.

The goal is to keep learning, keep practicing and improve with every project you create.
